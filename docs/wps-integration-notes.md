# WPS 集成验证说明(v0.5.0)

## 结论

本版本验证的是“加载项能否复用现有 core”,而不是发布一个可用的 WPS 加载项。设计文档 §3.2 明确排除 WPS 加载项作为首版产品范围;路线图 v0.5.0 要求的是最小读取与展示能力的可行性验证。因此实现保持为一个薄适配器,不引入 WPS 专有运行时依赖,文件级导入导出仍是正式回退路径。

## 复用的 core 能力

适配器只调用以下纯函数,不复制任何计算逻辑:

- `parseSalesWorkbook` / `applyColumnMapping`:把宿主工作簿数据转换为 `SalesData`。
- `computeMetrics`、`compareSnapshots`、`buildReport`、`buildChart`:产生指标、影响、报告与图表模型。
- `validateSalesData`:对宿主传入数据做结构校验。

宿主负责提供工作簿值与单元格地址,适配器负责把这些原始值喂给 core,并把 core 返回的模型交给宿主展示。计算与文案的唯一来源仍是 core。

## 最小读取契约

宿主需按 `Sales` 工作表约定提供 `region/previous/current` 三列。适配器接受与 `TabularInput` 同构的数据(表头 + 二维字符串行),经列映射确认后调用 core 得到 `SalesData`。这与 CSV 路径共用同一套 core 契约,避免为 WPS 另写一套解析。

## 支持的客户端版本与权限边界

- 目标:提供“读取活动工作簿单元格值 + 在侧边栏展示文本”能力的桌面版 WPS,最低以 2019 及以后的桌面版本作为验证基线。
- 权限:只读取用户显式选中的工作簿区域,不写回、不覆盖原文件、不访问其他工作表或本地文件系统。
- 网络:展示路径不发起网络请求;可选 AI 润色沿用 v0.4.0 的 opt-in 规则。
- 未验证:Web 版 WPS、移动端 WPS、自动同步、公式求值与跨工作簿引用。

## 回退路径

任何不满足上述边界的宿主(版本过旧、权限受限或字段不匹配)都应引导用户使用文件级导入导出:下载固定模板或示例,在本 Web 应用内完成导入与试改,再导出新的 `.xlsx`/`.docx`。该路径在 v0.1.0 已实现并经端到端验证。

## 验证状态

本版本提供适配器的自动化测试与一份能力矩阵,证明 core 可在不修改的前提下被宿主复用。真实 WPS 客户端的手动兼容性测试需要在装有对应客户端的环境中进行,不在 CI 范围内;仓库不对“已在真实 WPS 客户端验证”作任何声明。
