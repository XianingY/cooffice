# 用户指南

本指南面向首次使用者,覆盖 Web 版的核心流程（v1.5.0 界面）。核心编辑完全在浏览器本地完成;云端同步是可选功能,需服务方配置后端地址后才会出现。桌面版的安装、深色主题、拖拽导入、文件关联与更新检查见[桌面应用说明](desktop.md)。

## 一、准备输入文件

两种方式任选其一:

1. 在应用顶部点击「下载模板」或「下载示例」,得到固定结构的 `.xlsx`。
2. 准备一个 `.csv`,首行为列名,至少包含区域、上期销售额、当前销售额三列。

要求:文件不超过 10 MiB,数据 1～1000 行,区域名称唯一,数值为非负有限数字。公式、文本数字、空值和负数会被拒绝并给出具体行号。

## 二、导入

点击「导入 Excel 或 CSV」选择文件。

- `.xlsx`:必须包含 `Sales` 工作表,表头依次为 `region`、`previous`、`current`。
- `.csv`:导入后会弹出列映射对话框,自动猜测三列含义。请核对预览后点击「确认映射并导入」;取消则项目不变。

导入失败时,页面顶部会显示具体原因,当前项目不会被覆盖。

## 三、试改与预览

在数据表格中只修改「当前」列(「上期」只读)。每次修改会即时重算:

- 三项指标:总销售额、同比增长率、第一区域。
- 影响列表:指标、排名、报告结论的变化前后值。
- 报告预览:并排显示已确认报告与草稿报告。
- 区域柱状图:草稿数据的当前销售额分布。

点击任一影响项,会同时高亮对应的来源单元格与关联报告块,便于核验结论。

## 四、应用或撤销

- 「应用修改」:把草稿确认为新的 baseline,清空影响列表。
- 「撤销草稿」:放弃草稿,恢复为已确认版本。

存在未应用草稿时,工具栏的「导出来源」可切换「已确认版 / 草稿版」;选择草稿版时页面会提示已确认基线保持不变。导入新文件、打开云端项目或拖入文件前,若当前已有工作会先确认是否覆盖。

## 五、报告配置

在「报告配置」面板中:

- 勾选/取消勾选三块结论(总额、同比增长率、第一名)。
- 用上下箭头调整显示顺序。

配置会立即反映在报告中,并随本地项目与项目文件一起保存,刷新后仍然保留。

## 六、可选 AI 润色

点击「AI 润色设置」:

- 留空所有字段并确认,使用确定性模板(返回原文),不需要网络。
- 填写接口地址、模型名称与运行时密钥,可使用 OpenAI 兼容的润色服务。密钥只存在于该对话框内存中,确认后即清除,不写入本地存储、项目文件或日志。
- AI 仅润色文字。若结果改变了任何数字,会被数值护栏拒绝并回退到原文;报告数值始终由确定性计算产生。

不使用该功能时,应用不会发起任何网络请求。

## 七、导出

- 「导出 Excel」:按「导出来源」生成 `what-if-report-confirmed.xlsx` 或 `what-if-report-draft.xlsx`,不覆盖原文件。
- 「导出 Word」:生成 `what-if-report-confirmed.docx` 或 `what-if-report-draft.docx`,含标题、生成时间、指标摘要、报告块与来源说明。
- 「导出项目文件」:生成 `what-if-report-project.json`,含已确认数据、草稿与报告配置,可用于备份或在另一台设备继续。

## 八、本地恢复与清除

- 草稿会自动保存在浏览器本地(键 `what-if-report:project:v1`)。刷新或重新打开会恢复,包括报告配置。
- 旧版本的本地数据会在读取时自动迁移到当前格式,不会丢失。
- 点击「清除本地项目」需二次确认,确认后删除本地草稿、恢复虚构示例与默认报告配置。共享电脑用户离开前请主动清除。

## 九、隐私与边界

文件只在浏览器本地处理;不含分析、广告或追踪脚本。未配置后端时无需账号且不发起网络请求。Web 版离线首次打开取决于浏览器缓存;桌面版自带内嵌服务与本地数据,断网可完整使用。项目不解析任意公式、不做多人实时协作、不提供 AI 数值计算。

## 十、云端同步(可选)

当服务方启用了后端时,"云端同步"面板可用:

1. 注册或登录:密码至少 8 位,服务端使用加盐 scrypt 哈希存储。
2. 保存到云端:给项目命名并点击保存;草稿与已确认版本分别存储,其后再编辑点击"更新云端项目"。
3. 打开与搜索:在云端项目列表按名称搜索并打开;打开会替换当前本地工作区,请先按需导出备份。
4. 账号设置:可修改显示名称与密码;修改密码需要当前密码。
5. 导出项目文件:下载服务端生成的项目 JSON,与本地项目文件互操作。
6. 实时更新:多名成员同时打开同一项目时会收到变更提示,刷新即可看到最新数据。

安全说明:访问令牌仅存于内存,刷新令牌由浏览器以 HttpOnly Cookie 保存,JavaScript 无法读取;令牌不出现在 URL 中。退出登录会撤销当前会话家族。
